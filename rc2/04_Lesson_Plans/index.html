A Classroom Roadmap for RC2

Use these sheets alongside the workbook, articles, handouts, and visual theology resources.

How to Use These Sheets

Built for Teachers and Group Leaders

Each sheet provides a focused teaching path for one major theme in the cluster. Use them as presentation roadmaps, discussion guides, or weekly teaching outlines.

Before Class

Prepare the Theme

Review the corresponding workbook section, article, and visual theology graphic before teaching.

During Class

Guide the Discussion

Use the sheet to move through key ideas, Scripture emphasis, discussion, application, and prayer.

After Class

Reinforce the Lesson

Pair each Leader Sheet with the matching handout so participants can continue reflecting through the week.
